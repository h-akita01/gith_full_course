### 0.1 本書の方針
- 境界は、同値クラス（`models/equivalence.md`）のうち、値に順序があるクラスの端に置く。
- 1つの境界につき「境界直前・境界値・境界直後」の3点を取る（3点境界値分析）。境界値は、クラスの端にあたる値（クラスの内側の値）とする。
- 期間の端は、期間の両端を含むものとして扱う（HD-012）。
- 根拠は仕様書（SPEC-x / BR-x）とし、仕様書にない前提は人間による決定事項（HD-x）を根拠として明記する。

## 2. 搭乗日の境界（BVA-001〜BVA-022）

期間の切り替わりごとに、前の期間の上端と、後ろの期間の下端の2つの境界を取る。

## 3. 切り上げ前の運賃の境界（BVA-023〜BVA-024）

HD-008 に従い、切り上げ前の運賃を直接与える**仮の値**でテストする。境界は「100円単位ちょうど」（EQ-022）と「100円未満の端数あり」（EQ-021）の切り替わりに置く。値の刻みは1円とする（円単位の値。円未満の扱いは 3.1 を参照）。

| ID | 境界 | 境界直前 | 境界値 | 境界直後 | 根拠 |
|---|---|---|---|---|---|
| BVA-023 | 端数ありクラスの下端（12,601円） | 12,600円 → 12,600円（端数なし。そのまま） | 12,601円 → 12,700円 | 12,602円 → 12,700円 | SPEC-2 / BR-002 / EQ-021, EQ-022 / HD-008, HD-009 |
| BVA-024 | 端数ありクラスの上端（12,699円） | 12,698円 → 12,700円 | 12,699円 → 12,700円 | 12,700円 → 12,700円（端数なし。そのまま） | SPEC-2 / BR-002 / EQ-021, EQ-022 / HD-008, HD-009 |

### 3.1 円未満の端数の境界を作らない理由
- 円未満の端数がある値（EQ-023）は、HD-010 により運賃に直接切り上げを適用する。
- ただし、円未満の値の最小の刻み（0.01円、0.25円など）は、仕様にも人間による決定事項にも記載がない。刻みが決まらないと「境界直前・直後」の値が決まらないため、根拠のない境界値を作らないように、境界値分析の対象にしない。
- また、HD-001・HD-002 の条件では、実際の入力から円未満の端数は出ない（`models/equivalence.md` 2.5）。
- EQ-023 は、同値分割の代表値（12,600.25円 → 12,700円）でテストする。

### 5.1 自己レビューで判断した点
- 通常時の期間の端（例：1月6日、3月12日）は仕様に直接書かれていない。しかし、「上記以外」（BR-011）と隣り合うピーク期間の端（HD-012）から一意に決まるので、根拠があるものとして扱った。
- 12月31日 → 1月1日は、前後どちらもピーク1で運賃は変わらない。それでも、仕様に書かれた期間の端（PRD-11 の終了日、PRD-01 の開始日）なので境界として残した。
- 同じ切り替わりの2つの境界は日付が重なる（2.12）。この重なりは Phase 8（重複の整理）で扱う。本工程では、境界ごとの導出経路を残すために両方を記載した。
- 修正を要する問題は見つからなかった。
