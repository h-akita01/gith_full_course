## 1. 重複の確認

### 1.1 確認方法
CLAUDE.md Phase 8 に従い、次の5項目がすべて同じテストケースを重複候補とした。

| 項目 | 比べた内容 |
|---|---|
| 前提条件 | Background（区間の基本料金 10,000円、割引額 0円） |
| 入力条件 | 搭乗クラスタイプ、搭乗日（端数処理の Feature では切り上げ前の運賃） |
| 操作 | When（運賃を算出する / 運賃の100円未満の端数を処理する） |
| 期待結果 | Then の運賃 |
| テスト観点 | テストケースが確かめようとしていること（もとにしたテスト技法とモデル） |

69件の入力条件（搭乗クラス × 搭乗日、または切り上げ前の運賃）をすべて突き合わせた。

```gherkin

  運賃 = 基本運賃 − 運賃種別ごとの割引額（100円未満は切り上げ）
  基本運賃 = （区間の基本料金 + 搭乗クラスの加算料金）× 積算比率(%)

  Background:
    Given 区間の基本料金が 10,000円 の区間を指定している
    And 割引額が 0円 の運賃種別を指定している
```
